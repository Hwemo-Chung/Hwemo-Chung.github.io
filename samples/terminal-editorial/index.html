01 앱 구조·유지보수

오래 손대지 않은 하이브리드 앱은
세 곳에서 한꺼번에 막힙니다.

iOS 26 SDK 요건, Play 타깃 API 기한, Firebase Dynamic Links 종료가 같은 앱에 겹칩니다. 무엇이 막혔는지 영업일 2일 안에 보고서로 알려 드리며, 10곳까지는 무료입니다.

iOS2026-04-28부터 적용

App Store Connect
iOS 26 SDK 요건

2026년 4월 28일부터 App Store Connect는 iOS 26 SDK로 빌드한 앱만 받습니다. 그렇게 빌드하지 않은 앱은 업데이트를 올릴 수 없습니다.

Android기한 지남 · 연장 신청 가능

Google Play
타깃 API 기한

Play 타깃 API 기한은 이미 지났습니다. 다만 연장 신청은 아직 할 수 있습니다.

Links서비스 종료

Firebase
Dynamic Links 종료

Firebase Dynamic Links는 종료됐습니다. 이 링크에 기대던 앱은 다른 방식으로 옮겨야 합니다.

진행 순서

진단 → 보고서 → 수정 → 재등록
  1. STEP 01

    진단

    무료 진단을 신청하면 App Store, Play, 링크 가운데 무엇이 막혔는지 확인합니다.

    10곳까지 무료
  2. STEP 02

    보고서

    무엇이 막혔는지를 보고서로 정리해 알려 드립니다.

    영업일 2일 안에
  3. STEP 03

    수정

    보고서에서 짚은 곳을 고칩니다. 작업 범위와 제외 항목, 가격은 서비스 페이지에 적어 두었습니다.

    범위·가격 공개
  4. STEP 04

    재등록

    고친 앱을 다시 스토어에 올립니다. 그 뒤의 운영은 월 단위 유지보수로 이어 갈 수 있습니다.

    유지보수로 연결

스토어 업로드가 막혔다면
진단부터 받아 보세요.

모집 중10곳까지 무료영업일 2일 안에 보고서
무료 진단 신청 → 서비스와 가격 보기

유지보수 — Ionic·Capacitor·Android WebView 앱의 운영을 월 단위로 지원합니다. Stabilizer는 월 $1,200, Pilot 한 달은 $400입니다. 새 앱 개발과 전면 재작성은 맡지 않습니다.

02 제품

직접 만들고, 직접 운영하는 제품.

무료로 푼 것, 파는 것, 만드는 중인 것이 함께 있습니다. 지금 상태는 카드마다 적어 두었습니다.

macOS 26 (Tahoe)무료

HotLauncher

macOS 26(Tahoe)에서 런치패드가 사라졌습니다. 자주 쓰는 앱을 최대 20개까지 전역 단축키에 하나씩 붙여 두고 바로 엽니다. 광고와 구독이 없고 소스를 공개했습니다.

macOS · 네이티브 앱판매 중

LumosZipForMac

Mac에서 AES-256 비밀번호 ZIP을 터미널 없이 다룹니다. 광고와 구독이 없고, Apple Silicon과 Intel에서 모두 돌아가는 네이티브 앱입니다. 지금은 베타 할인가로 팝니다.

CLI · 데스크톱 앱대기자 모집

Threads Analyzer

스레드 계정의 글 전체를 12시트짜리 엑셀 리포트로 정리합니다. 평균 대신 중앙값과 데드율로 봅니다. CLI는 무료 오픈소스이고, 데스크톱 앱은 $29입니다.

소셜 PWA라이브

Pebblez

광고와 추천 알고리즘이 없는 작은 소셜 PWA입니다. 한 줄(페블)을 남기면 아는 사람들 사이로 퍼집니다. 오프라인에서도 쓸 수 있고 무료입니다.

웹 · 색각 체험무료

Color Vision Lab

색약 유형별로 사진이 어떻게 보이는지 체험하고, 13장의 도판으로 색각을 선별하는 테스트도 할 수 있습니다. 사진은 브라우저 안에서만 처리되며 서버로 전송되지 않습니다. 선별용이며 진단이 아닙니다.

  • 사진→이미지 용량 줄이기
  • 사진→상품 사진 흰 배경
  • 사진→증명사진 만들기
  • 사진→사진 속 물체 지우기
  • 집·상품 사진→벽 색 바꾸기
  • 집·상품 사진→유튜브 썸네일 만들기
  • 영상→무음 구간 자르기
  • 영상→영상에 자막 입히기
  • 소리→보컬 분리
  • 자막→자막 번역
  • 문서→PDF를 Word 문서로 바꾸기
  • 웹·개발→웹페이지 전체 캡처
