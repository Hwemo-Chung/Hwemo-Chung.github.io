01앱 구조·유지보수

오래 손대지 않은 하이브리드 앱은 세 가지에 한꺼번에 걸립니다.

무엇이 막혔는지 영업일 2일 안에 보고서로 알려 드립니다. 10곳까지는 무료입니다.

  1. iOS 빌드

    App Store Connect

    2026년 4월 28일부터 App Store Connect는 iOS 26 SDK로 빌드한 앱만 받습니다.

    iOS 26 SDK 빌드만 접수
  2. Android 타깃 API

    Play target API

    Play 타깃 API 기한은 이미 지났습니다. 다만 연장 신청은 아직 할 수 있습니다.

    기한 경과 · 연장 신청 가능
  3. 딥링크

    Firebase Dynamic Links

    Firebase Dynamic Links는 종료됐습니다. Dynamic Links 이전은 레거시 작업으로 다룹니다.

    서비스 종료

진단에서 스토어 재등록까지, 네 단계

새 앱 개발과 전면 재작성은 맡지 않습니다.

  1. 01

    진단

    무엇이 업데이트를 막고 있는지 앱을 살펴봅니다.

  2. 02

    보고서영업일 2일

    막힌 지점을 보고서로 정리해 알려 드립니다.

  3. 03

    수정

    보고서에서 짚은 항목을 고칩니다.

  4. 04

    스토어 재등록

    고친 앱을 다시 스토어에 올립니다.

스토어 업로드가 막혔다면 진단부터 받아 보세요.매달 이어지는 운영 지원은 Mobile Production Retainer로 받습니다. Stabilizer 월 $1,200, Pilot 한 달 $400.
