01 · App Rescue

오래 손대지 않은 앱은
세 곳에서 한꺼번에 막힙니다.

2026년 4월 28일부터 App Store Connect는 iOS 26 SDK로 빌드한 앱만 받습니다. 같은 앱에 Play 타깃 API 기한과 Firebase Dynamic Links 종료도 겹칩니다.

  • App Store Connect

    iOS 26 SDK 필수

    2026년 4월 28일부터 적용

    App Store Connect는 iOS 26 SDK로 빌드하지 않은 앱을 받지 않습니다.

  • Google Play

    타깃 API 기한

    기한 지남 · 연장 신청 가능

    Play 타깃 API 기한은 이미 지났습니다. 다만 연장 신청은 아직 할 수 있습니다.

  • Firebase

    Dynamic Links

    서비스 종료

    Firebase Dynamic Links는 종료됐습니다. Dynamic Links 이전은 레거시 작업으로 해 온 일입니다.

오래 손대지 않은 하이브리드 앱은 셋 모두에 걸립니다. 무엇이 막혔는지부터 확인합니다.

진단에서 재등록까지, 네 단계

10곳까지는 진단이 무료입니다.

  1. 진단

    지금 앱이 어디에서 막혔는지 확인합니다. 신청은 진단 페이지에서 받습니다.

  2. 보고서 영업일 2일

    무엇이 막혔는지 영업일 2일 안에 보고서로 알려 드립니다.

  3. 수정

    보고서에 적힌 막힌 지점을 고칩니다. 새 앱 개발과 전면 재작성은 맡지 않습니다.

  4. 스토어 재등록

    업데이트가 막혔던 앱을 다시 스토어에 올립니다.

스토어 업로드가 막혔다면 진단부터 받아 보세요.

02 · Products

직접 만들어 내놓은 제품

광고와 구독 없이 쓰는 Mac 앱부터 작은 소셜 PWA까지. 상태는 지금 그대로 적었습니다.

  • 무료

    HotLauncher

    macOS 26(Tahoe)에서 런치패드가 사라졌습니다. 자주 쓰는 앱을 최대 20개까지 전역 단축키에 하나씩 붙여 두고 바로 엽니다. 광고와 구독이 없고 소스를 공개했습니다.

    제품 페이지GitHub
  • 판매 중

    LumosZipForMac

    Mac에서 AES-256 비밀번호 ZIP을 터미널 없이 다룹니다. 광고와 구독이 없고, Apple Silicon과 Intel에서 모두 돌아가는 네이티브 앱입니다. 지금은 베타 할인가로 팝니다.

    제품 페이지지금 구매
  • 라이브

    Pebblez

    광고와 추천 알고리즘이 없는 작은 소셜 PWA입니다. 한 줄(페블)을 남기면 아는 사람들 사이로 퍼집니다. 오프라인에서도 쓸 수 있고 무료입니다.

    서비스 열기
  • 무료

    Color Vision Lab

    색약 유형별로 사진이 어떻게 보이는지 체험하고, 13장의 도판으로 색각을 선별하는 테스트도 해 봅니다. 사진은 브라우저 안에서만 처리됩니다. 선별용이며 진단이 아닙니다.

    서비스 열기GitHub
  • 대기자 모집

    Threads Analyzer

    스레드 계정의 글 전체를 12시트짜리 엑셀 리포트로 정리합니다. 평균 대신 중앙값과 데드율로 봅니다. CLI는 무료 오픈소스이고, 데스크톱 앱은 $29입니다.

    제품 페이지
  • Building

    Burnline

    로컬 우선 AI 비용 추적 도구입니다. 모델별·날짜별 지출을 보고 월 한도를 정합니다. 프롬프트는 내 컴퓨터 밖으로 나가지 않습니다.

    제품 페이지대시보드
