01 앱 구조·유지보수

오래 손대지 않은 하이브리드 앱은 세 군데에서 한꺼번에 막힙니다.

무엇이 막혔는지 영업일 2일 안에 보고서로 알려 드립니다. 진단은 10곳까지 무료입니다.

  • App Store Connect

    2026. 4. 28 —iOS 26 SDK 빌드만 접수

    2026년 4월 28일부터 App Store Connect는 iOS 26 SDK로 빌드한 앱만 받습니다.

  • Google Play

    타깃 API —기한 경과, 연장 신청 가능

    Play 타깃 API 기한은 지났지만 연장 신청은 아직 할 수 있습니다.

  • Firebase

    Dynamic Links —서비스 종료

    Firebase Dynamic Links는 종료됐습니다.

진단에서 재등록까지, 네 단계

  1. 01

    진단 10곳까지 무료

    앱이 어디에서 막혔는지 확인합니다.

  2. 02

    보고서 영업일 2일

    막힌 지점을 보고서로 정리해 알려 드립니다.

  3. 03

    수정

    보고서에서 확인한 막힌 지점을 고칩니다.

  4. 04

    스토어 재등록

    업데이트를 다시 스토어에 올립니다.

새 앱 개발과 전면 재작성은 맡지 않습니다.

매달 맡기는 운영 지원은 Mobile Production Retainer로 받습니다. Ionic·Capacitor·Android WebView 앱 대상이며 Stabilizer는 월 $1,200, Pilot 한 달은 $400입니다.

02 제품

직접 만드는 제품 여섯 가지.

Mac 앱, 소셜 PWA, 분석 도구까지. 지금 상태는 뱃지에 적힌 그대로입니다.

무료

HotLauncher

macOS 26(Tahoe)에서 런치패드가 사라졌습니다. 자주 쓰는 앱을 최대 20개까지 전역 단축키에 하나씩 붙여 두고 바로 엽니다. 광고와 구독이 없고 소스를 공개했습니다.

LumosZipForMac

Mac에서 AES-256 비밀번호 ZIP을 터미널 없이 다룹니다. 광고와 구독이 없고, Apple Silicon과 Intel에서 모두 돌아가는 네이티브 앱입니다. 지금은 베타 할인가로 팝니다.

Pebblez

광고와 추천 알고리즘이 없는 작은 소셜 PWA입니다. 한 줄(페블)을 남기면 아는 사람들 사이로 퍼집니다. 오프라인에서도 쓸 수 있고 무료입니다.

무료

Color Vision Lab

색약 유형별로 사진이 어떻게 보이는지 체험하고, 13장의 도판으로 색각을 선별합니다. 사진은 브라우저 안에서만 처리됩니다. 선별용이며 진단이 아닙니다.
