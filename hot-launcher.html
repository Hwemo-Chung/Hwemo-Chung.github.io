런치패드가 사라진 macOS 26, 단축키 한 번이면 그 앱이 뜹니다.

HotLauncher는 메뉴바에 상주하는 macOS 네이티브 앱 런처입니다. macOS 26에서 없어진 런치패드(Launchpad)를 흉내 내는 대신, 전역 단축키를 누르면 지정해 둔 앱이 바로 실행됩니다. 광고 없고, 구독 없고, 인덱싱도 없습니다.

GitHub에서 소스 보기 개발자에게 커피 한 잔 · $1.99

Apple 공증 전입니다. 미리 빌드한 .app을 사이트에 올리지 않습니다. 소스에서 빌드하세요. Gatekeeper가 막을 수 있습니다.

In English

Apple removed Launchpad in macOS 26 (Tahoe). Its replacement — a Spotlight-based Apps view — is slower when you just want to open one specific app. HotLauncher is an alternative, not a restored Launchpad grid: a free native menubar app that lets you bind up to 20 apps to simple global hotkeys, so one keystroke opens the app you chose.

  • Up to 20 slots (two pages of 10), each app bound to a global hotkey
  • Free — no ads, no subscription; the only network access is the donation link
  • Not notarized yet: no prebuilt download, you build from source (commands below)
  • Requires macOS 26+ on Apple Silicon

Source is on GitHub — the install commands below work as-is. Tip jar: $1.99 via PayPal. Questions: tolaria@naver.com.

  • 전역 단축키 → 지정한 .app만 실행

  • 로그인 시 자동 실행 (시스템 로그인 항목)
  • 설정은 기기 안 JSON. 네트워크는 기부 클릭뿐

런치패드가 사라졌습니다

Apple은 macOS 26(Tahoe)에서 런치패드(Launchpad)를 제거하고, Spotlight와 통합된 새 ‘앱’ 보기로 바꿨습니다. 시스템 설정에는 이전 런치패드로 되돌리는 공식 옵션이 없습니다.

HotLauncher는 그 격자 화면을 복원하는 앱이 아니고, Spotlight를 대체하지도 않습니다. 자주 쓰는 앱을 전역 단축키에 연결해 두고 키 한 번으로 바로 여는, 다른 방식의 대안입니다.

주요 기능

전역 단축키

Carbon 핫키. 다른 앱이 앞에 있어도 지정한 조합으로 앱을 켭니다.

메뉴바만

독 아이콘 없음(LSUIElement). Settings에서 앱과 키를 고릅니다.

로그인 실행

시스템 로그인 항목 API. 켜면 부팅 후 메뉴바에 올라옵니다.

자주 묻는 질문

macOS 26에서 런치패드가 왜 사라졌나요?

Apple이 macOS 26(Tahoe)부터 런치패드(Launchpad)를 제거하고 Spotlight와 통합된 새 ‘앱’ 보기로 대체했습니다. 설정에서 끄고 켤 수 있는 변경이 아닙니다.

사라진 런치패드를 되돌릴 수 있나요?

시스템 설정에는 이전 런치패드로 되돌리는 공식 옵션이 없고, 베타 시기에 알려졌던 터미널 우회도 정식 버전에서는 막혔습니다. HotLauncher는 런치패드를 복원하는 앱이 아니라, 전역 단축키로 지정한 앱을 바로 여는 대안입니다.

왜 다운로드 파일이 없나요?

Apple 공증 전의 바이너리를 사이트에 올리지 않습니다. GitHub 소스에서 빌드하면 본인 머신에서 서명한 앱이 생깁니다.

어떤 Mac에서 되나요?

macOS 26 이상, Apple Silicon. 테스트는 macOS 26.6.2에서 했습니다.

유료인가요?

앱은 무료입니다. 원하면 PayPal로 $1.99 기부가 가능합니다. 기능과 무관합니다.
