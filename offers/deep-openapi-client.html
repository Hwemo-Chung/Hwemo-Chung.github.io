OpenAPI 타입 클라이언트 생성 파이프라인

API 명세가 바뀌면 Angular 서비스와 타입을 자동으로 다시 만들고, 어긋나면 CI에서 잡습니다.

백엔드 명세와 프론트엔드 타입이 달라서 생기는 사고를 줄입니다. openapi-generator나 orval로 생성 파이프라인을 붙이고, 생성 결과가 깨지면 CI가 머지를 막습니다. BFF를 두거나 클라이언트가 여럿인 팀에 맞습니다.

가격₩400,000 ~ ₩1,000,000
납기3~7영업일, 입금 확인 후 시작
준비할 것OpenAPI나 Swagger URL 또는 파일
견적 메일 보내기

받는 것

  • 생성 스크립트
  • CI 단계
  • 사용 가이드(import 경로)
  • 호환이 깨지는 변경 감지 방법

이런 작업에 맞습니다

  • NestJS Swagger로 Angular 클라이언트 생성
  • 버전 헤더 분기

주문 방법

위 버튼을 누르면 제목과 양식이 채워진 메일이 열립니다. 회사, 저장소나 스택, 겪고 있는 문제, 희망 일정, 예산을 적어 보내 주세요. 범위를 확인해 금액과 일정을 회신하고, 입금이 확인되면 시작합니다. 합의한 범위를 넘는 작업은 따로 견적을 드립니다. 메일 앱이 열리지 않으면 tolaria@naver.com으로 직접 보내 주세요.
