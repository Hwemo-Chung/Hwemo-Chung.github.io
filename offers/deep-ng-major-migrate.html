Angular Major Migration Plan

Angular 메이저 마이그레이션 실행 계획

vN→vN+k 경로, 깨질 패키지, 단계 PR 단위까지 문서+스파이크

단순 버전 숫자 올리기가 아닙니다. 의존성 그래프, 폐기 API, 테스트 공백, 스토어 빌드까지 포함해 ‘몇 개 PR로 어떻게 건너갈지’ 실행 계획을 납품합니다. 전량 구현은 별도 계약이며, 스파이크 1건(대표 깨짐 지점)까지 포함 가능합니다.

가격
₩800,000 ~ ₩2,500,000

납기: 1~2주 · 입금 후 착수

필요 자료

저장소 읽기 + package-lock + 목표 Angular 버전

납품물

  • 현재→목표 버전 경로표
  • 차단 패키지·대체안
  • PR 단위 마이그레이션 순서
  • 리스크/공수 밴드 + 스파이크 결과(옵션)

예시

  • Angular 12→18
  • View Engine 잔재 정리
  • Ionic 동시 메이저

시장 포지션

엔터프라이즈 Angular 업그레이드 컨설팅 입구. 구현 수주~수개월 업셀.

제외: 전량 구현 보증 없이 범위 무한 확장, 침투 테스트 전체, 인프라 전면 재구축. 구현 스프린트는 별도 SOW.
