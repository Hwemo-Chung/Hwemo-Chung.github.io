Google 시트와 API 양방향 동기화

운영팀은 익숙한 Google 시트를 그대로 쓰고, 시트 내용은 정해진 주기로 API와 맞춥니다.

TypeScript나 Apps Script로 시트의 행을 REST API 데이터와 맞춥니다. 운영 화면은 시트로 두고, 야간 배치가 두 쪽을 일치시키는 방식입니다. Make.com 같은 노코드 도구로 부족한 부분을 채울 때도 맞습니다.

가격₩500,000 ~ ₩1,500,000
납기1~2주, 입금 확인 후 시작
준비할 것시트 공유, API 명세와 토큰
견적 메일 보내기

받는 것

  • 열과 필드 매핑 표
  • 증분 동기화와 전체 동기화 중 선택
  • 충돌 시 우선순위(시트 우선 또는 API 우선)
  • 실행 스케줄과 실패 기록 시트

이런 작업에 맞습니다

  • 재고 시트를 쇼핑몰 API에 반영
  • 문의 시트를 CRM에 등록
  • 출고 상태를 시트로 되가져오기
