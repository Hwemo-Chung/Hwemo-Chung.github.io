딥링크·page.link 생존 감사

인쇄물, 문자, 웹에 들어간 링크를 모두 열어 보고 살아 있는지 표로 정리합니다. 복구 방향은 1페이지로 드립니다.

Firebase Dynamic Links가 종료된 뒤 page.link 주소가 아직 열리는지 한 번에 확인합니다. 유입이 없는 링크라면 복구를 권하지 않습니다.

가격₩99,000 ~ ₩250,000
납기2~4영업일, 입금 확인 후 시작
준비할 것검사할 URL 목록(최대 수량은 미리 합의합니다)
견적 메일 보내기

받는 것

  • URL별 HTTP 상태 표
  • page.link 주소와 커스텀 도메인 구분
  • 복구가 필요한지 판정(판단에 쓴 유입 가정을 함께 적습니다)
  • 리다이렉트 구현이 필요할 때의 견적

알아 두실 점

서버 리다이렉트 구현은 포함하지 않습니다.

주문 방법

위 버튼을 누르면 제목과 양식이 채워진 메일이 열립니다. 회사, 저장소나 스택, 겪고 있는 문제, 희망 일정, 예산을 적어 보내 주세요. 범위를 확인해 금액과 일정을 회신하고, 입금이 확인되면 시작합니다. 합의한 범위를 넘는 작업은 따로 견적을 드립니다. 메일 앱이 열리지 않으면 tolaria@naver.com으로 직접 보내 주세요.
