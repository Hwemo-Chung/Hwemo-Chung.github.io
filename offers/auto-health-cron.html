API Health Cron

API·웹 헬스체크 크론

분/시간 단위 핑 + 연속 실패 시 알림

단순 업타임. TypeScript fetch로 상태코드·지연을 기록하고, N회 실패 시 메일/슬랙/디스코드 웹훅. 상용 Uptime 대체 입문용.

가격
₩150,000 ~ ₩400,000

납기: 2~4영업일 · 입금 후 착수

필요 자료

URL 목록 + 알림 웹훅/메일

납품물

  • 체크 대상 URL 목록
  • 스케줄(크론 식)
  • 알림 채널 1개
  • 최근 결과 로그(시트 또는 JSON)

예시

  • 프로덕션 /health
  • 결제 웹훅 엔드포인트
  • 정적 사이트 200 확인

시장 포지션

UptimeRobot급 니즈의 사내 구축. 저단가 진입 후 관측 스택 업셀.

제외: 전량 구현 보증 없이 범위 무한 확장, 침투 테스트 전체, 인프라 전면 재구축. 구현 스프린트는 별도 SOW.
