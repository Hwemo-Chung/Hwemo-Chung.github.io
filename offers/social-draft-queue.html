블로그 초안 큐 자동화

RSS/노션/시트 소스 → 마크다운·CMS 초안만 생성 (공개 예약은 사람)

수집·요약·초안 저장까지 자동화하고, 공개/예약은 편집자가 누릅니다. 검색 스팸·복제 콘텐츠 양산을 범위에서 제외합니다.

적법·약관 범위

타 사이트 본문 무단 복제·자동 SEO 스팸 게시 제외. 라이선스 있는 소스·요약·오리지널 작성 전제.

가격
₩400,000 ~ ₩1,000,000

납기: 1~2주 · 입금 후 착수

필요 자료

소스 + 초안 저장 위치 + (선택) CMS API

납품물

  • 소스 2종까지 (RSS/시트/폴더)
  • 중복 URL 제거
  • 초안 저장(레포/노션/CMS draft API)
  • 편집 체크리스트 템플릿

예시

  • 업계 뉴스 → 내부 위키 초안
  • 제품 업데이트 → 릴리스 노트 초안

시장 포지션

콘텐츠 운영 SaaS의 ‘draft pipeline’. 자동 퍼블리시는 약관·품질 리스크로 옵션화.

하지 않는 것: 무단 대량 DM/댓글, 팔로우·좋아요 조작, 계정 공유 강요, 수신동의 없는 메일 폭탄, 검색 스팸 양산, 로그인 벽 무단 스크래핑.
