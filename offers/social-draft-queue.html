블로그 초안 큐 자동화

RSS, 노션, 시트에서 글감을 모아 Markdown이나 CMS 초안으로 저장합니다. 공개와 예약은 사람이 합니다.

수집, 요약, 초안 저장까지 자동으로 하고 공개 버튼은 편집자가 누릅니다. 자동 공개는 약관과 품질 문제가 있어 기본 범위에 넣지 않습니다.

납기1~2주, 입금 확인 후 시작
준비할 것소스, 초안 저장 위치, CMS API(선택)

  • 소스 2종까지(RSS, 시트, 폴더 중)
  • 중복 URL 제거
  • 초안 저장(저장소, 노션, CMS draft API 중)
  • 편집 체크리스트 템플릿

알아 두실 점

다른 사이트 본문을 그대로 복제하거나 검색 스팸 글을 자동 게시하는 일은 하지 않습니다. 라이선스가 있는 소스를 요약하거나 직접 쓴 글을 전제로 합니다.

주문 방법

위 버튼을 누르면 제목과 양식이 채워진 메일이 열립니다. 회사, 저장소나 스택, 겪고 있는 문제, 희망 일정, 예산을 적어 보내 주세요. 범위를 확인해 금액과 일정을 회신하고, 입금이 확인되면 시작합니다. 합의한 범위를 넘는 작업은 따로 견적을 드립니다. 메일 앱이 열리지 않으면 tolaria@naver.com으로 직접 보내 주세요.
