RSS 뉴스 초안 파이프라인

RSS와 뉴스를 정해진 주기로 모으고, 조건에 맞는 항목만 골라 초안으로 쌓습니다. LLM 요약은 선택입니다.

TypeScript 워커가 RSS나 API를 돌며 조건에 맞는 항목을 노션, 시트, 저장소에 저장합니다. 자동 게시까지 붙이면 플랫폼 정책에 걸릴 수 있어서 기본 범위는 초안 저장까지입니다.

가격₩400,000 ~ ₩1,000,000
납기1~2주, 입금 확인 후 시작
준비할 것소스 URL, 저장 위치, LLM API 키(요약을 쓸 때)
견적 메일 보내기

받는 것

  • 소스 목록과 필터 규칙
  • 주기 수집 작업
  • 초안 저장소(시트, 노션, Markdown 중 선택)
  • 중복 URL 제거

이런 작업에 맞습니다

  • 업계 뉴스 모음
  • 경쟁사 블로그 모니터링
  • 채용 공고 수집
