Angular/TypeScript CI 파이프라인

PR을 올릴 때마다 lint, test, build가 돌고, 하나라도 실패하면 머지를 막습니다.

Angular 저장소나 Nx 모노레포에 GitHub Actions 또는 GitLab CI를 붙입니다. Node 버전 고정, 캐시, 빌드 결과물 보관까지 설정해서 로컬에서는 되는데 CI에서만 깨지는 일을 줄입니다.

가격₩300,000 ~ ₩800,000
납기2~5영업일, 입금 확인 후 시작
준비할 것GitHub 또는 GitLab 저장소와 Actions 권한
견적 메일 보내기

받는 것

  • push와 PR용 워크플로 YAML
  • npm ci, lint, test, build 단계
  • Node 버전 고정 또는 버전별 매트릭스
  • README에 실행 방법과 문제 해결 안내

이런 작업에 맞습니다

  • Angular 18 이상 앱
  • 라이브러리 패키지 publish dry-run
  • Storybook 빌드(선택)

주문 방법

위 버튼을 누르면 제목과 양식이 채워진 메일이 열립니다. 회사, 저장소나 스택, 겪고 있는 문제, 희망 일정, 예산을 적어 보내 주세요. 범위를 확인해 금액과 일정을 회신하고, 입금이 확인되면 시작합니다. 합의한 범위를 넘는 작업은 따로 견적을 드립니다. 메일 앱이 열리지 않으면 tolaria@naver.com으로 직접 보내 주세요.
