Angular CI Gate

Angular/TypeScript CI 파이프라인

PR마다 lint · test · build 자동 실행, 실패 시 머지 차단

Angular(또는 Nx 모노레포) 저장소에 GitHub Actions/GitLab CI를 붙입니다. 노드 버전 고정, 캐시, 아티팩트 보관까지 포함해 ‘로컬에선 되는데 CI에서 깨짐’을 줄입니다.

가격
₩300,000 ~ ₩800,000

납기: 2~5영업일 · 입금 후 착수

필요 자료

GitHub/GitLab 저장소 + Actions 권한

납품물

  • push/PR 워크플로 YAML
  • npm ci + lint + test + build
  • Node 버전 매트릭스 또는 고정
  • README 실행/트러블슈팅 절

예시

  • Angular 18+ 앱
  • 라이브러리 패키지 publish dry-run
  • 스토리북 빌드 옵션

시장 포지션

프론트 팀 필수 인프라. 크몽 ‘CI/CD 세팅’ 상위 전환 상품.

제외: 전량 구현 보증 없이 범위 무한 확장, 침투 테스트 전체, 인프라 전면 재구축. 구현 스프린트는 별도 SOW.
