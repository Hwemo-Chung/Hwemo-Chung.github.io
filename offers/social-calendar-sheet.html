콘텐츠 캘린더(시트) 운영 자동화

시트에 적은 초안과 예약 시각을 승인 대기 목록으로 정리합니다. 승인 없이 자동으로 게시하지 않습니다.

마케팅 시트에서 게시 후보를 모으고, 상태가 approved인 행만 다음 단계로 넘기는 TypeScript 또는 Apps Script 파이프라인입니다. 사람이 승인해야 넘어가도록 기본 설정합니다. 예약 게시 도구를 바꾸는 상품이 아니고, 승인 절차를 갖추는 상품입니다.

가격₩300,000 ~ ₩800,000
납기5~10영업일, 입금 확인 후 시작
준비할 것운영 시트, 채널 목록, 승인 담당자
견적 메일 보내기

받는 것

  • 시트 구조(채널, 본문, 미디어, 상태)
  • 상태 흐름(draft, review, approved, done)
  • 리마인더와 마감 알림 1채널

이런 작업에 맞습니다

  • 블로그와 SNS를 함께 쓰는 주간 캘린더
  • 캠페인 UTM 열 고정
  • 승인 요청 슬랙 알림

알아 두실 점

실제 게시는 담당자가 직접 하거나 공식 API로 합니다. 공식 API 연동은 별도 범위입니다. 스팸 자동 게시나 가짜 참여 유도는 하지 않습니다.

주문 방법

위 버튼을 누르면 제목과 양식이 채워진 메일이 열립니다. 회사, 저장소나 스택, 겪고 있는 문제, 희망 일정, 예산을 적어 보내 주세요. 범위를 확인해 금액과 일정을 회신하고, 입금이 확인되면 시작합니다. 합의한 범위를 넘는 작업은 따로 견적을 드립니다. 메일 앱이 열리지 않으면 tolaria@naver.com으로 직접 보내 주세요.
