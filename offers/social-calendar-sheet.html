콘텐츠 캘린더(시트) 운영 자동화

시트에 쓴 초안·예약 시각 → 승인 큐로 정리 (자동 무단 게시 없음)

마케팅 시트를 기준으로 게시 후보를 모으고, ‘승인됨’ 행만 다음 단계로 넘기는 TypeScript/Apps Script 파이프라인입니다. 플랫폼에 무단 대량 게시하지 않으며, 사람 승인 게이트를 기본값으로 둡니다.

적법·약관 범위

플랫폼 자동 스팸 게시·가짜 참여 유도 없음. 고객 소유 계정·공식 API/수동 게시만.

가격
₩300,000 ~ ₩800,000

납기: 5~10영업일 · 입금 후 착수

필요 자료

운영 시트 + 채널 목록 + 승인자

납품물

  • 시트 스키마(채널·본문·미디어·상태)
  • 상태머신: draft → review → approved → done
  • 크론으로 리마인더/마감 알림 1채널
  • 게시 실행은 수동 또는 공식 API(별도 범위)

예시

  • 주간 블로그·SNS 혼합 캘린더
  • 캠페인 UTM 열 고정
  • 승인 슬랙 알림

시장 포지션

콘텐츠 팀 운영 배관. Buffer/Later 대체 입문이 아니라 ‘승인 워크플로’가 판매 포인트.

제외: 전량 구현 보증 없이 범위 무한 확장, 침투 테스트 전체, 인프라 전면 재구축. 구현 스프린트는 별도 SOW.
