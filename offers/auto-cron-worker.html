TypeScript 크론 워커 구축

Cloudflare Cron / GitHub Actions / 서버 crontab 중 환경에 맞게 주기 작업 1종 가동

Node/TypeScript로 배치 잡 1개를 설계·구현·스케줄 등록까지 합니다. 예: 매일 리포트 생성, API 폴링, 시트 동기화, 실패 시 메일/슬랙 알림. Angular 프론트와 무관하게 백오피스 자동화에 적합합니다.
