TypeScript 크론 워커 구축

정해진 시간마다 도는 TypeScript 작업 1개를 만들어 Cloudflare Cron, GitHub Actions, 서버 crontab 중 맞는 곳에 올립니다.

Node와 TypeScript로 배치 작업 1개를 설계하고 구현해 스케줄 등록까지 합니다. 매일 리포트 만들기, API 폴링, 시트 동기화 같은 일에 맞고, 실패하면 메일이나 슬랙으로 알립니다. 프론트엔드와 상관없는 백오피스 자동화에 씁니다.

가격₩400,000 ~ ₩1,200,000
납기3~10영업일 (잡 복잡도), 입금 확인 후 시작
준비할 것실행 환경(클라우드나 서버) 접근 권한, 대상 API와 시트 권한
견적 메일 보내기

받는 것

  • 작업 명세 1페이지(입력, 출력, 실패 시 처리)
  • TypeScript 구현과 환경변수 목록
  • cron, Actions, Workers cron 중 한 곳에 등록
  • 실패 알림 1채널(이메일 또는 웹훅)

이런 작업에 맞습니다

  • 매일 23:00 매출 CSV 수집
  • 1시간마다 헬스체크
  • 주 1회 만료 토큰 정리

알아 두실 점

작업은 1개입니다. 납기는 작업 복잡도에 따라 3~10영업일 사이에서 정합니다. 구축 후 유지보수는 포함하지 않습니다.

주문 방법

위 버튼을 누르면 제목과 양식이 채워진 메일이 열립니다. 회사, 저장소나 스택, 겪고 있는 문제, 희망 일정, 예산을 적어 보내 주세요. 범위를 확인해 금액과 일정을 회신하고, 입금이 확인되면 시작합니다. 합의한 범위를 넘는 작업은 따로 견적을 드립니다. 메일 앱이 열리지 않으면 tolaria@naver.com으로 직접 보내 주세요.
