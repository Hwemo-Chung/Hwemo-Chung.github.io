채널별 초안 패키지 (원문 1개 기준)

블로그 글 하나로 X, LinkedIn, Threads, 뉴스레터용 초안을 만듭니다. 게시 전에 사람이 확인합니다.

한 콘텐츠를 채널마다 길이와 말투에 맞게 나눠 초안 묶음을 만듭니다. 여러 채널에 동시에 자동 게시하는 봇은 아닙니다. 같은 문구가 여러 곳에 반복 게시되지 않도록 검수 단계를 둡니다.

가격₩150,000 ~ ₩400,000 (템플릿) / 건당 운영은 별도
납기템플릿 구축 3~5일, 입금 확인 후 시작
준비할 것원문 샘플 3개, 채널 목록
견적 메일 보내기

받는 것

  • 채널별 글자 수 템플릿
  • UTM 자동 부착(선택)
  • 초안 출력(시트 또는 Markdown)
  • 금지 표현 체크리스트

이런 작업에 맞습니다

  • 릴리스 노트로 SNS 글 3종 만들기
  • 채용 공고를 LinkedIn과 블로그용으로 나누기

알아 두실 점

가격은 템플릿 구축 비용입니다. 글마다 초안을 만들어 드리는 운영 대행은 별도 비용입니다. 다른 회사 콘텐츠를 허락 없이 다시 올리거나 가짜 후기를 만들지 않습니다.

주문 방법

위 버튼을 누르면 제목과 양식이 채워진 메일이 열립니다. 회사, 저장소나 스택, 겪고 있는 문제, 희망 일정, 예산을 적어 보내 주세요. 범위를 확인해 금액과 일정을 회신하고, 입금이 확인되면 시작합니다. 합의한 범위를 넘는 작업은 따로 견적을 드립니다. 메일 앱이 열리지 않으면 tolaria@naver.com으로 직접 보내 주세요.
