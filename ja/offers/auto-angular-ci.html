Angular/TypeScript CI パイプライン

PR を上げるたびに lint、test、build が回り、1 つでも失敗するとマージを防ぎます。

AngularリポジトリまたはNxモノリポにGitHub ActionsまたはGitLab CIを貼り付けます。 Node バージョン固定、キャッシュ、ビルド結果物のアーカイブまで設定することで、ローカルではなりますが、CI でのみ壊れることを減らします。

価格₩300,000 ~ ₩800,000
納期2～5営業日、入金確認後開始
準備するGitHub または GitLab リポジトリと Actions 権限
見積もりメールを送信

受け取るもの

  • pushとPR用のワークフローYAML
  • npm ci, lint, test, build ステップ
  • Node バージョン固定またはバージョン別マトリックス
  • READMEの実行方法とトラブルシューティングガイド

このような仕事に合います

  • Angular 18以上のアプリ
  • ライブラリパッケージ publish dry-run
  • Storybook ビルド（選択）
