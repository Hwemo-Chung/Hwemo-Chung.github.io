ポリシーのスケジュールと実際の影響

診断と見積もりは、下記の公式文書の内容に基づいています。

  • Apple SDK、2026-04-28から。 アップロードに Xcode 26 と iOS 26 SDK が必要で、修正プログラムの送信が妨げられることがあります。すでにインストールされているアプリはデバイスから削除されません。
  • Play Target API、2026-08-31（延長申請は11/1まで）。 新規アプリとアップデートには API 36 が必要です。既存のアプリがAPI 35未満の場合、アプリターゲットよりも高いOSデバイスの新規ユーザーに提供が制限されます。世界中のすべての新規ユーザーとすべての端末でブロックされるわけではありません。
  • Firebase Dynamic Links, 2025-08-25 終了。 page.link アドレスが 404 を返す場合があります。流入がある場合にのみ復旧する価値があり、すべてのアプリが今売上を失っているわけではありません。
  • Cordova、決まった日付なし。 プラグインと古い CLI のため、最新の SDK に追従するのが難しい場合があります。公式にアーカイブされた、あるいはメンテナンスモードに入ったと見なす根拠はありません。
