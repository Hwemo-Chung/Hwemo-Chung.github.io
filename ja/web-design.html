すべての制作物に含まれるもの

上のサンプルとこのページで確かめられることだけを書いています。

  • フレームワークを使わない静的な HTML・CSSサンプルはそれぞれ HTML ファイル1つです。フレームワークやビルドの手順なしで、静的なホスティングにそのまま置けます。
  • 幅390pxのスマートフォン表示を確認9つのサンプルすべてで、幅390pxの画面で横にはみ出さないことを確認しました。
  • 検索向けの head 設定タイトル、説明文、canonical、Open Graph、JSON-LD を入れます。いまご覧のこのページがその例です。サンプルページは検索結果に出ないよう noindex にしています。
  • 「視差効果を減らす」設定に対応端末で動きを減らす設定（prefers-reduced-motion）をオンにすると、アニメーションを止めます。
  • WCAG AA の文字コントラストを確認文字と背景のコントラストが WCAG AA の基準（通常の文字 4.5:1、大きな文字 3:1）を超えているか、サンプルごとに測定しました。

制作の流れ

  1. 1お問い合わせ

    作りたいページと気に入ったサンプルを、メールでお知らせください。

  2. 2スタイルを選ぶ

    サンプルから1つを選びます。

  3. 3初稿

    選んだスタイルにいただいた内容を入れ、初稿をお見せします。

  4. 4修正

    初稿をご覧になって直したい点をお知らせいただければ、反映します。

  5. 5納品

    完成した HTML・CSS ファイルをお渡しします。
