Burnline

Burnline は、自分のマシン上の AI エージェントと API 使用ログを読み取り、月次予算に対するコストをモデル別、日別に表示します。プロンプトはマシン上に残ります。

まだ販売していません。CLI と HTML レポートはプロトタイプとして存在しますが、決済ページやクラウドへのログインはありません。マルチモデルのコーディング エージェントを使っていて、リリース情報を受け取りたい場合は、待機リストに登録してください。現時点では Burnline の代金を送金しないでください。

仕組み

ログをローカルにインポートする

Burnline で Claude Code または JSONL の使用ログを指定します。コストの数値を得るためにプロンプトをアップロードする必要はありません。

API 呼び出しごとに料金を算出

レートが文書化されたオフライン モデル カタログは、トークンをドルに変換します。合計は実際の請求額と照合するためのものです。

月間上限を設定する

予算を米ドルで設定します。Burnline は 80% で警告し、100% でフラグを立てます。記録用にデータを CSV としてエクスポートできます。

Burnline が対象としないこと

Burnline は完全なプロンプト可観測性クラウドではなく、v1 にはエンタープライズ SSO もありません。Helicone 規模のパイプラインが必要な場合は、そちらを使ってください。Burnline は、少ない設定で正確なコスト数値を知りたい開発者向けです。

本番運用中のモバイルアプリのサポートが今すぐ必要な方は モバイルリテーナーをご覧ください。
