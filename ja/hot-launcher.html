HotLauncher

よく使うMacアプリを最大20個までグローバルショートカットに1つずつ貼り付けておき、キーを押すとすぐに開くメニューバーアプリです。無料でソースが公開されています。

macOS 26（Tahoe）でLaunchpadが抜け、Spotlight内のAppsランチャーがその場に代わる。アイコンを好きな場所に置くことはできず、アプリの電源を入れるには検索結果を待つことがよくあります。 HotLauncherはその画面を通過しません。

GitHubからソースを取得する PayPalで$ 1.99を寄付する

macOS 26以降、Apple Silicon Macで動作します。まだApple公証前だからアプリファイルは配布せず、ソースからビルドしてインストールします。

すること

ショートカットでアプリを開く

他のアプリの書き込み中に指定したキーを押すと、そのアプリが開きます。検索やインデックス作成は行いません。

スロット 20 個

1画面に10個（2列5行）ずつ、2ページに分けて配置します。

メニューバーのみに常駐

毒アイコンがありません。メニューバーのSettingsでアプリとキーを選択します。

ログイン時に自動実行

をオンにすると、システムログインエントリに登録され、起動後にメニューバーに表示されます。

ネットワークを書き込まない

設定は、このMacのJSONファイルに保存します。ネットワークは、寄付リンクをクリックしたときにのみ書き込みます。

インストール

macOS 26、Swift 6.3、Xcode Command Line Toolsが必要です。端末で以下の4行を実行すると、ApplicationsフォルダにHotLauncherがインストールされます。

git clone https://github.com/Hwemo-Chung/HotLauncher.git
cd HotLauncher/HotLauncher
bash scripts/bundle.sh
bash scripts/install.sh

今は adhoc 署名なので、システム評価 (spctl) の結果が rejected となります。ビルドしたアプリを別のMacにコピーするとGatekeeperがブロックされることがありますので、使用するMacで直接ビルドしてください。

よくある質問

ランチパッドはどこに行きましたか？

macOS 26 Tahoeではなくなり、SpotlightのAppsが代わりになります。 HotLauncherはアイコングリッドを復活させることなく、頻繁に開くアプリにショートカットを付けます。

AlfredやRaycastを書いていますか？

もしそうなら、このアプリは必要ないかもしれません。ランチャーウィンドウなしでアプリ20個だけキーに貼り付けておきたいときに使うアプリです。

なぜダウンロードファイルがないのですか？

Apple の公証を受ける前のバイナリはサイトに掲載されません。 GitHubソースからビルドすると、Macで署名したアプリが作成されます。

どの Mac でできますか？

macOS 26以降、Apple Silicon Mac。 macOS 26.6.2でテストしました。

有料ですか？

アプリは無料です。 PayPalで$ 1.99を寄付できますが、寄付の有無と機能は関係ありません。
