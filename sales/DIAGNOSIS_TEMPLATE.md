## 3. Play 타겟 API 축

| 확인 | 결과 |
|------|------|
| targetSdkVersion (aapt 등) | |
| 2026-08-31 영향 가능성 | 있음 / 제한적 / 낮음 |
| 연장(11/1) 검토 가치 | 있음 / 없음 |

**공식 요지 (과장 금지):**  
신규 앱·업데이트는 API 36(예외 있음). 기존 앱이 API 35 미만이면 **앱 타겟보다 높은 OS를 쓰는 기기의 신규 사용자**에게 제공이 제한될 수 있습니다.  
전 세계 모든 신규 사용자·모든 기기 차단이 아닙니다.

**내부 배포·신규 설치 0이면:** 영향이 작을 수 있음 → 솔직히 적음.
