Free · macOS 26+ · Apple Silicon

단축키 한 번이면, 그 앱이 뜹니다.

HotLauncher는 메뉴바에 상주하는 macOS 네이티브 앱입니다. 전역 단축키를 누르면 설정해 둔 앱이 실행됩니다. 광고 없고, 구독 없고, 인덱싱도 없습니다.

GitHub에서 소스 보기 개발자에게 커피 한 잔 · $1.99

Apple 공증 전입니다. 미리 빌드한 .app을 사이트에 올리지 않습니다. 소스에서 빌드하세요. Gatekeeper가 막을 수 있습니다.

  • 전역 단축키 → 지정한 .app만 실행
  • 슬롯 20개 · 한 화면 10개(2열×5줄) · 페이지 2장
  • 로그인 시 자동 실행 (시스템 로그인 항목)
  • 설정은 기기 안 JSON. 네트워크는 기부 클릭뿐

설치

권장 소스에서 빌드 
git clone https://github.com/Hwemo-Chung/HotLauncher.git
cd HotLauncher/HotLauncher
bash scripts/bundle.sh
bash scripts/install.sh
  • macOS 26 · Swift 6.3 · Xcode CLT
  • /Applications/HotLauncher.app 에 설치
알아두실 점
공증 전
  • 현재 adhoc 서명 — spctl --assess 는 rejected
  • 다른 Mac에 복사하면 Gatekeeper가 막을 수 있음
  • 본인 머신에서 소스 빌드하는 경로가 안전합니다

주요 기능

전역 단축키

Carbon 핫키. 다른 앱이 앞에 있어도 지정한 조합으로 앱을 켭니다.

메뉴바만

독 아이콘 없음(LSUIElement). Settings에서 앱과 키를 고릅니다.

로그인 실행

시스템 로그인 항목 API. 켜면 부팅 후 메뉴바에 올라옵니다.

자주 묻는 질문

왜 다운로드 파일이 없나요?

Apple 공증 전의 바이너리를 사이트에 올리지 않습니다. GitHub 소스에서 빌드하면 본인 머신에서 서명한 앱이 생깁니다.

어떤 Mac에서 되나요?

macOS 26 이상, Apple Silicon. 테스트는 macOS 26.6.2에서 했습니다.

유료인가요?

앱은 무료입니다. 원하면 PayPal로 $1.99 기부가 가능합니다. 기능과 무관합니다.
