개인정보처리방침 — Pixel Diary (픽셀 다이어리)

최종 수정일: 2026-08-18

요약. Pixel Diary는 계정 없이 쓰는 오프라인 다이어리입니다. 일기·미디어·설정은 모두 기기 내부 앱 전용 저장소에만 보관되며, 서버로 수집·전송하지 않습니다. 광고·분석·크래시 리포팅 SDK가 없습니다.

1. 운영자와 문의

이 정책은 Pixel Diary(픽셀 다이어리 / Pixel Diary / ピクセルダイアリー, 이하 "앱")의 Android 앱에 적용됩니다.

  • 운영자: Chung Hwemo (Lumos)
  • 개인정보 문의: tolaria@naver.com (주소 등 추가 정보는 요청 시 제공)

2. 처리 정보와 목적

앱은 계정 없이 사용할 수 있습니다. 아래 정보는 기기의 앱 전용 저장 공간에서 작성·표시·복원·설정 유지에 쓰입니다.

정보목적저장 위치
일기 본문·날짜·태그·블록 배치작성·검색·조회기기 내부 Hive 저장소
텍스트·드로잉·스티커·사진/영상 블록페이지 표시기기 내부 앱 전용 저장소
사용자가 선택기에서 고른 사진·영상일기 첨부읽은 뒤 앱 전용 media/에 사본
테마·알림 시각·앱 잠금 설정설정 유지기기 내부 저장소
PIN 검증 정보앱 화면 잠금기기 내부 저장소
복구 지점복원·형식 변경 중 복구앱 전용 저장 영역

앱은 이름·이메일·전화번호·연락처·위치·광고 식별자·계정 정보를 서버에 수집하지 않습니다.

3. 카메라·선택기·알림·생체 인증

기능사용 시점거부·취소 시
카메라사진 블록 촬영촬영만 불가, 다른 기능 사용 가능
시스템 사진·동영상 선택기갤러리 항목 선택선택 미디어 추가만 불가
알림사용자가 리마인더를 켤 때리마인더만 사용 불가
생체 인증앱 잠금 활성화 시PIN으로 잠금 해제 가능

앱은 지문·얼굴 데이터를 읽거나 저장하지 않고, OS의 생체 인증 성공/실패 결과만 받습니다. 시스템 선택기는 사용자가 고른 항목에만 접근합니다(전체 라이브러리 접근 아님).

4. 네트워크·제3자·외부 내보내기

계정 서버, 클라우드 동기화, 광고·분석·크래시 리포팅 SDK가 없습니다. 일기와 가져온 미디어 사본은 앱 서버로 전송되지 않습니다.

사용자가 JSON/PDF를 시스템 저장 대화상자로 내보내거나 다른 앱·클라우드로 공유하면, 이후 처리는 해당 서비스와 사용자의 선택에 따릅니다. 앱은 앱 저장소 밖으로 나간 파일을 통제하지 않습니다.

5. 보관과 삭제

  • 일기와 앱 전용 미디어 사본은 사용자가 삭제하거나 앱을 제거할 때까지 기기에 남습니다.
  • JSON/PDF 내보내기 파일은 앱 밖에 있으므로 사용자가 저장 위치에서 직접 삭제합니다.
  • 앱은 서버 계정을 운영하지 않아 서버 계정 삭제 절차가 없습니다. 삭제 문의는 이메일로 안내합니다.
  • Android 자동 백업은 비활성화되어 있으며, 사용자가 JSON으로 직접 백업·복원합니다.

6. 홈 화면 위젯

위젯을 쓰면 최근 페이지 썸네일이나 연속 기록이 홈 화면에 표시될 수 있습니다. 런처·OS·제조사가 표시 내용을 별도 캐시할 수 있으며, 그 캐시의 보관 기간은 앱이 보장할 수 없습니다.

7. 앱 잠금의 한계

앱 잠금은 잠긴 앱 화면 접근을 막는 기능이며, 일기 파일을 암호화하지 않습니다. 루팅·부트로더 잠금 해제 기기에서 저장 공간에 직접 접근하면 내용이 읽힐 수 있습니다.

8. 아동의 개인정보

앱은 아동을 주요 대상으로 설계되지 않았으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

9. 변경 및 문의

처리 목적·저장 방식·네트워크 전송·제3자 SDK·위젯 노출·삭제 방식이 바뀌면 최종 수정일과 내용을 갱신하고, 중요한 변경은 앱 업데이트로 안내합니다.
