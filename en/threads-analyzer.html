Threads Analyzer

Import all posts from the thread account into the Meta Threads API and create a 12-sheet Excel report. By calculating the median instead of the average, you can see the performance over time hidden by a single viral post.

The command line CLI is free and open source and is available now. A desktop app that can be used with a click without installation is being prepared, and the launch price is $29(Regular price $39) This is a one-time payment. You can get it for $19 if you join the waitlist.

12 sheets in the report

Once you run it, an Excel file containing one account will appear.

  • All Posts: Date, views, likes, and engagement are all included in each post and can be filtered.
  • Insight Ranking: Top 30 are selected based on views, engagement, like rate, and virality.
  • Time zone analysis: Crosses 24 hours and the day of the week to produce the median and dead rate.
  • Daily view count trend: Daily time series of up to 730 days and 7-day moving average.
  • Snapshot growth trend: Saves the follower count on every run. The API keeps no history, so the app records it itself.
  • Viral in-depth analysis: Calculate the top 1% based on account size.
  • Content Optimization: Performance by number of characters and topic tags.
  • The remaining five sheets are Like Rate, Monthly Trends, Follower Demographics, Growth Insights, and Growth Strategy.

What you need before writing

  • You must create the Meta developer app yourself. Meta opens insights only through apps created by the account owner. Buying the desktop app does not remove this step; it takes about 10 minutes with the on-screen wizard. If that sounds like too much, we recommend not buying it.
  • The follower demographics sheet only appears when you have more than 100 followers due to Meta policy. The remaining 11 sheets just need posts.
  • Time zone and character count analysis only makes decisions on sections with more than 30 samples.

Frequently Asked Questions

Where does my data go?

Does not send anywhere. There is no server, and the Meta API is called directly from your computer and the resulting Excel file is saved only on your computer. Token is local Place it in the file .env and lock the permissions to 600.

How long does it take?

The first collection takes about 10 minutes for 2,000 posts. From the second time, it uses the cache and takes 1 to 2 minutes.

Can your followers at least write?

Yes. If you have less than 100 followers, only the Follower Demographics sheet will be blank, and the remaining 11 sheets will remain as is.

Why is the app paid when the CLI is free?

The engine is the same, and the app was created so that there is no need to set up a terminal, Python, or certificate. If you don't want to waste your time, you can use the free version.
