Included in every project

Only what you can check in the samples above and on this page.

  • Static HTML & CSS, no frameworkEach sample is a single HTML file. It goes straight onto static hosting, with no framework or build step.
  • Mobile layout checked at 390pxAll nine samples were checked on a 390px-wide screen for horizontal overflow.
  • Search-ready headTitle, description, canonical, Open Graph and JSON-LD. This page is an example. The sample pages are set to noindex so they stay out of search results.
  • Respects reduced motionWhen reduced motion (prefers-reduced-motion) is on, animations are turned off or paused.
  • WCAG AA text contrast checkedText-to-background contrast was measured in every sample against WCAG AA (4.5:1 for normal text, 3:1 for large text).
