LumosZipForMac

This is a macOS app that creates and unpacks password-protected ZIP files using AES-256 (WinZip standard). No terminal, no ads, no subscriptions.

It is currently a beta that has not yet been notarized by Apple, so it is sold as a one-time purchase at a discounted price. You can get updates when the full version is released.

A payment link is being prepared. To buy the beta, please send an email to tolaria@naver.com. We will reply with a download link and installation instructions.

Features

AES-256 encryption

It follows the WinZip AES-256 standard, and you can also choose AES-128. Encryption is done with Apple CommonCrypto, the key is derived with PBKDF2, and integrity is checked with HMAC.

Compatible with other compression programs

Files created with this app will open with the same password in standard tools such as 7-Zip and Keka. You can also pick ZipCrypto for older programs, but the app marks it as "weak."

Split compression and large capacity

Compresses large files by splitting them into several pieces. There are size presets for CD, DVD, and FAT32 as well as custom sizes, and ZIP64 handles very large files.

Multilingual file name

Saves the file name as UTF-8.

Offline operation

The files never leave your Mac. It works without an internet connection.

Requirements

  • macOS 13 or later
  • It is a universal app that supports both Apple Silicon and Intel Mac, so Rosetta is not required. This is a native app created with SwiftUI.
  • Since the beta is not yet notarized, you need to allow it once in macOS the first time you run it. The guide we send explains how to allow it with a single Terminal command or in System Settings. The full version will be notarized and open without a warning.

Frequently Asked Questions

Is encryption secure?

We did not write our own encryption. LumosZip uses Apple CommonCrypto's proven implementation, following the WinZip AES-256 standard, so archives open with the same password in 7-Zip or Keka.

Why do I get a warning when I run it for the first time?

Because the beta has not been notarized by Apple, macOS displays a confirmation warning. If you allow it once according to the guide, it will open right away from then on.
