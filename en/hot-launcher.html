HotLauncher

This is a menu bar app that allows you to place up to 20 frequently used Mac apps one by one on a global shortcut key and open them immediately when you press the key. It's free and the source is open.

In macOS 26 (Tahoe), Launchpad is gone and the Apps launcher inside Spotlight takes its place. You can't put icons where you want, and launching an app often means waiting for search results. HotLauncher skips that screen.

Runs on macOS 26 or later, Apple Silicon Mac. Since it has not yet been notarized by Apple, the app file will not be distributed, but will be built and installed from source.

What it does

Open apps with shortcut keys

Even while using another app, pressing the specified key opens that app. There is no searching or indexing.

20 slots

Arrange 10 items (2 columns, 5 lines) per screen, divided into 2 pages.

Only resides in the menu bar

There is no dock icon. Select an app and key from Settings in the menu bar.

Automatically runs upon login

If you turn it on, it is registered as a system login item and appears on the menu bar after booting.

No network access

Settings are saved to a JSON file on this Mac. The network is used only when you click the donation link.

Installation

Requires macOS 26, Swift 6.3, and Xcode Command Line Tools. Running the four lines below in your terminal will install HotLauncher in your Applications folder.

git clone https://github.com/Hwemo-Chung/HotLauncher.git
cd HotLauncher/HotLauncher
bash scripts/bundle.sh
bash scripts/install.sh

This is an adhoc signature, so the system evaluation (spctl) result is rejected. If you copy the built app to another Mac, Gatekeeper may block it, so please build it directly on the Mac you will be using.

Frequently Asked Questions

Where did Launchpad go?

Gone in macOS 26 Tahoe, replaced by Apps in Spotlight. HotLauncher adds shortcuts to frequently opened apps, rather than bringing back the icon grid.

What if I already use Alfred or Raycast?

Then you might not need this app. It is for when you just want up to 20 apps bound to keys, without a launcher window.

Why is there no download file?

Binaries are not posted on the site until Apple has notarized them. Building from the GitHub source produces an app signed on your own Mac.

Which Mac does this work on?

macOS 26 or later, Apple Silicon Mac. Tested on macOS 26.6.2.

Is it paid?

The app is free. You can donate $1.99 via PayPal, but donating does not change any features.
