업데이트가 막힌 Cordova·Ionic 앱을 다시 스토어에 올립니다.

2026년 4월 28일부터 App Store Connect는 iOS 26 SDK로 빌드한 앱만 받습니다. 같은 앱에 Play 타깃 API 기한과 Firebase Dynamic Links 종료도 겹칩니다. 무엇이 막혔는지 영업일 2일 안에 보고서로 알려 드리며, 10곳까지는 무료입니다.

무료 진단 신청 제품 보기

독립 계약으로 일합니다. 새 앱 개발과 전면 재작성은 맡지 않습니다.

무료

제품 페이지GitHub

LumosZipForMac

판매 중

Mac에서 AES-256 비밀번호 ZIP을 터미널 없이 다룹니다. 광고와 구독이 없고, Apple Silicon과 Intel에서 모두 돌아가는 네이티브 앱입니다. 지금은 베타 할인가로 팝니다.

레거시 하이브리드 앱 진단

모집 중

App Store Connect는 iOS 26 SDK로 빌드하지 않은 앱을 받지 않습니다. Play 타깃 API 기한은 지났지만 연장 신청은 아직 할 수 있고, Firebase Dynamic Links는 종료됐습니다. 오래 손대지 않은 하이브리드 앱은 셋 모두에 걸립니다. 10곳까지 무료로 진단합니다.
