Cordova로 만든 앱, 8월 31일부터
신규 사용자에게 노출이 막힙니다.

구글 플레이는 2026년 8월 31일부터 신규 앱과 앱 업데이트에 Android 16(API 36) 타겟을 요구합니다. 기존 앱도 Android 15(API 35) 미만을 타겟하면 더 높은 OS를 쓰는 신규 사용자에게 노출되지 않습니다. Cordova 기반 앱은 플러그인 생태계가 유지보수 모드로 들어가 이 상향을 스스로 따라가지 못합니다.

2026년 8월 31일 마감

연장 신청 기한은 2026년 11월 1일입니다. 연장은 시간을 벌 뿐 요건을 없애지 않습니다.

무료 진단 신청 (10곳 한정) 우리 앱이 해당되는지 직접 확인
  • 진단은 공개 배포된 APK만 사용합니다. 소스코드·계정·스토어 권한을 요구하지 않습니다
  • Angular 7 + Ionic 4 + Cordova 앱을 Angular 20 + Ionic 8 + Capacitor 8로 이전한 실적이 있습니다
  • Cordova 네이티브 플러그인을 직접 작성해 본 경험이 있습니다 (블루투스 프린터 연동)
  • 특정 기업·고용주와의 제휴를 주장하지 않습니다. 고객사명은 공개하지 않습니다

우리 앱이 해당되는지 직접 확인하는 법

개발자가 사내에 있다면 5분이면 됩니다. 진단을 맡기지 않아도 됩니다.

확인 항목방법해당되면
Cordova 여부 APK 압축 해제 후 assets/www/cordova.js 또는 assets/www/cordova_plugins.js 존재 확인 Cordova 앱 확정
타겟 API aapt dump badging app.apk 실행 후 targetSdkVersion 확인 34 이하면 8/31 영향권
방치 기간 플레이 스토어 상세의 “최종 업데이트” 날짜 18개월 이상이면 위험

확인이 어렵거나 사내에 안드로이드 담당이 없으면 아래 무료 진단을 쓰시면 됩니다.

진행 방식

1단계

무료 진단

앱 이름만 주시면 됩니다. 현재 타겟 API, Cordova 플러그인 목록, 상향을 막는 항목, 예상 공수를 1장으로 정리해 보내드립니다.

2단계

긴급 대응

이전 없이 타겟 API만 올려 스토어 노출을 유지합니다. 마감이 급할 때 선택합니다.

3단계

Capacitor 이전

Cordova 런타임을 Capacitor로 교체하고 플러그인을 현행 대체품으로 옮깁니다. 웹 코드는 대부분 그대로 재사용합니다.

범위와 비용

아래 금액은 범위 가설입니다. 확정 견적은 무료 진단 이후에만 드립니다. 앱 규모, 플러그인 개수, 네이티브 커스텀 코드 유무에 따라 크게 달라집니다.

자주 묻는 질문

진단이 왜 무료인가요?

공개된 APK만 분석하므로 제 비용이 거의 들지 않습니다. 레퍼런스가 필요해서 초기 10곳까지만 무료로 하고 이후에는 유료로 전환합니다. 영업용 미끼가 아니라, 해당 없는 앱이면 “해당 없음”이라고 그대로 회신합니다.

소스코드를 줘야 하나요?

진단 단계에서는 필요 없습니다. 앱 이름 또는 플레이 스토어 링크만 있으면 됩니다. 실제 작업 단계에서는 저장소 접근이 필요하며, 그때 계약과 비밀유지 조건을 먼저 정합니다.

연장 신청하면 되는 것 아닌가요?

연장 기한은 2026년 11월 1일까지입니다. 요건 자체가 사라지지 않고, 내년에 또 상향됩니다. 연장은 이전 작업을 준비할 시간을 버는 용도로만 의미가 있습니다.

Capacitor로 옮기면 웹 코드를 다시 짜야 하나요?

대부분 그대로 씁니다. 교체 대상은 네이티브 런타임과 플러그인 계층입니다. 다만 오래된 Angular나 폐기된 플러그인에 의존하고 있으면 그 부분은 추가 작업이 생깁니다. 무엇이 걸리는지는 진단 리포트에 그대로 적어 드립니다.

한 사람에게 맡겨도 되나요?

범위를 좁게 계약하시면 됩니다. 진단 → 긴급 대응 → 이전 순서로 끊어서 진행하고, 각 단계마다 산출물을 받고 멈출 수 있습니다. 락인 없습니다.

일본 기업도 되나요?

일본어 실무 대응 가능합니다. 문의 메일을 일본어로 보내셔도 됩니다.
